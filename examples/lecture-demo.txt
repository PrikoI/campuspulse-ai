Рекурсия — способ организации вычисления, при котором функция вызывает саму себя. Для завершения рекурсии нужен базовый случай. Каждый следующий вызов должен приближать вычисление к базовому случаю.

Перегрузка функций в C++ позволяет определить несколько функций с одинаковым именем и разными списками параметров. Компилятор выбирает подходящую функцию по аргументам вызова. Один только возвращаемый тип не отличает перегруженные функции.

При оценке длительности лабораторной работы полезно отдельно учитывать чтение условия, реализацию, проверку граничных случаев и подготовку объяснения результата.
