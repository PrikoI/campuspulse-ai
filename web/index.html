Данные и режим работы

Задания и настройки сохраняются в хранилище этого браузера. Материалы хранятся только в памяти вкладки. При запросе они передаются локальному серверу на этом компьютере.

В локальном режиме Gemini не вызывается. Маршрут выбирает обычный алгоритм; план рассчитывает программа. Журнал показывает действия, а не внутренние размышления модели.

При подключении GitHub сервер обращается к api.github.com. Загруженные материалы туда не отправляются. Облачное развёртывание и платёжные операции не выполняются.

После подключения ключа Gemini запрос и результаты вызванных инструментов передаются Google через Developer API. В Free Tier Google может использовать данные для улучшения продуктов. Не загружай конфиденциальные материалы. Ключ хранится только в памяти сервера, отдельно для сессии браузера, до отключения, перезапуска или 12 часов.

Перед каждым модельным шагом проверяется, что у проекта ключа отключён биллинг. Если проверка не прошла, запрос блокируется. Проверка отражает состояние на момент запроса; не подключай биллинг к этому проекту.

Подключить настоящий Gemini

Gemini выбирает MCP-инструменты, читает их результаты и отвечает по твоим данным. Модель: Gemini 3.1 Flash-Lite.

  1. Открой Google AI Studio → API keys ↗.
  2. Выбери проект с Free Tier и отключённым биллингом. Создай ключ кнопкой Create API key. Не выбирай Set up billing, Upgrade или оплату.
  3. Вставь ключ здесь. Он не попадёт в задания, экспорт или журнал.

Ключ ещё не подключён.

Для проверки проекта нужен вход Google ADC с доступом к этому проекту и API Keys API. Если подтвердить отключённый биллинг не удастся, запрос к модели не уйдёт. При исчерпании бесплатной квоты приложение покажет ошибку.

При подключении запросы и найденные фрагменты отправляются Google. В Free Tier они могут использоваться для улучшения продуктов. Не добавляй секретные материалы.
