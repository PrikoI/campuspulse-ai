# Фактическая проверка

Проверено 17 октября 2026 на Windows, Python 3.12.14.

## Успешно

- **29 автотестов, 0 ошибок и 0 пропусков.** Прогон с поддержкой auth keys и ошибок MCP завершился за 7,077 секунды. Живой Gemini ни в одном тесте не вызывается.
- Настоящий MCP stdio: initialize, обнаружение четырёх пользовательских инструментов, вызов инструментов, отдельные данные в новой сессии.
- Браузерный сценарий: загрузка учебных примеров, расчёт 11 блоков / 7,5 часа, отдельное предупреждение о просроченном задании. Это учебные данные, не задания реального курса.
- Браузерная загрузка `lecture-demo.txt` и запрос «Найди в материалах: рекурсия»: возвращены цитата и имя файла через MCP.
- Реальный четырёхстраничный PDF пользователя прочитан через локальный HTTP endpoint; извлечено 12 294 символа, текст не обрезан. Исходный документ не включён в архив проекта.
- Экспорт `.ics` через интерфейс: 11 событий, даты UTC, максимальная длина строки после folding — 75 байт. События во внешнем календаре не создавались.
- Локальный сервер отвечает HTTP 200; status показывает `mode=local`, `cloud_allowed=false`, `cloud_deployed=false`.
- Проверки Host/Origin отклоняют сторонний домен; PDF без текста возвращает понятную ошибку OCR.
- Dry-run развёртывания ничего не создаёт; `--execute` без разрешения завершается отказом до импорта облачного SDK и сетевых запросов.
- Интерфейс просмотрен в браузере на настольном и узком экране. На узком экране календарь прокручивается отдельно, общая страница не расширяется горизонтально.
- Презентация: 8 слайдов, редактируемый текст; структура PPTX, геометрия, шрифты и повторный импорт Artifact Tool проверены. Все 8 слайдов просмотрены по PNG. Проверка в Microsoft PowerPoint не выполнялась.

## Новое подключение Developer API

Проверены: ключ определяется по настоящему проекту, разрешено только `billingEnabled=false`, неизвестный/включённый биллинг и ошибка сети блокируют генерацию до создания клиента. Проверка повторяется перед каждым шагом модели. Тест Developer API вызывает настоящий MCP stdio с подменённой моделью и сохраняет function call IDs. Ошибка 429 не запускает повторную генерацию, другой тариф или локальную подмену ответа. Сессии изолированы, отключение удаляет ключ, удалённая ошибка не раскрывает ключ.

Через настоящий Google Cloud Billing API получен HTTP 200 и `billingEnabled=false` для выбранного проекта. Для проверки ключей включён API Keys API; настройки биллинга не менялись.

После отдельного согласия пользователя приняты условия Google; создан ключ CampusPulse Free Tier в выбранном проекте. Ключ введён непосредственно в локальный интерфейс, не выводился в чат, исходники или журнал. Google API подтвердил проект 306153323125 и отключённый биллинг.

Предприняты два живых запроса Gemini. Настоящий ответ не получен: соединение с generativelanguage.googleapis.com разрывается до HTTP-ответа. Независимые проверки requests и httpx без ключа дали WinError 10054. DNS разрешается, системный HTTP-прокси не настроен. Биллинг не менялся, Vertex и сторонние прокси не использовались. Положительные тесты с подменённой моделью не подтверждают живую генерацию.

## Внешнее ограничение

Реальный запрос GitHub к публичному `modelcontextprotocol/python-sdk` вернул **HTTP 403: rate limit exceeded**. Успешное получение живых issues в этой среде не подтверждено. Обработка 403 сообщает ошибку пользователю и не подменяет ответ примерами. Разбор issues, исключение PR и работа с milestone проверены на контролируемом ответе в тесте.

Успешная генерация Gemini, размещение вычислительных ресурсов GCP, размещение в Agent Engine, проверка облачного endpoint, публикация репозитория, отправка сообщений организаторам и любые платёжные действия.
