# Gemini Developer API в LMS

LMS поддерживает Google Gen AI SDK Interactions API с серверным API-ключом.
Это отдельный режим от Vertex AI: он не использует ADC, не создаёт облачные
ресурсы и не передаёт ключ в браузер или MCP-процесс.

## Локальная настройка

Создайте или обновите приватный `.env` в корне проекта. Если настройка
`CAMPUSPULSE_LLM_PROVIDER` уже есть, замените её значение — не добавляйте
повторную строку:

```dotenv
CAMPUSPULSE_LLM_PROVIDER=gemini
CAMPUSPULSE_GEMINI_MODEL=gemini-3.8-flash
CAMPUSPULSE_GEMINI_ENABLED=1
CAMPUSPULSE_GEMINI_API_KEY=your-new-google-api-key
```

Возьмите ключ в Google AI Studio и вставьте его только в `.env`. Этот файл
исключён из Git. Если ключ уже был опубликован или отправлен в чат, отзовите
его в Google AI Studio и создайте новый. Переменные окружения процесса имеют
приоритет над `.env`. После настройки перезапустите `start-lms.cmd`, откройте
интерфейс, войдите как студент и выберите `LLM` в режиме помощника.

Модель и вызовы отключены по умолчанию; `CAMPUSPULSE_GEMINI_ENABLED=1` включает
запросы явно. Замените имя модели в `.env`, если она недоступна для вашего
ключа или проекта. Состояние провайдера показывает API `/api/v1/status`, но
`live_verified=false` означает, что реальный запрос не проверялся.

## Поведение и ограничения

Вызов выполняется через `client.interactions.create` с ключом на сервере,
тайм-аутом 45 секунд, `store=False`, не более трёх запросов модели и восьми
вызовов инструментов на запрос. Поддерживаются функции LMS с текущими
серверными проверками сессии, allowlist инструментов и подтверждений действий.
История передаётся как текстовые ходы; результаты инструментов не сохраняются
между запросами Gemini. Ошибки провайдера не раскрывают тело ответа или ключ.

Вызов LLM в этом приложении требует подключённой учебной базы Firestore и
студенческой сессии. Без базы используйте режим `Без AI`; он не вызывает модель.
