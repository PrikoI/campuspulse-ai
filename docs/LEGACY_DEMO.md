# Архив: прежнее самостоятельное демо CampusPulse AI

Этот документ сохранён как исторический материал. Команды, модели, состояние
подключений и интерфейс ниже не описывают текущий LMS-бэкенд. Актуальные инструкции:
[README.md](../README.md), [LMS API](LMS_API.md). Старые примеры не использовать
как источник академических данных или тестовые наборы для LMS.

Помощник студенту для второй задачи Build with AI / GDG Astana: учебный план, дедлайны, текущие GitHub issues и поиск по своим материалам через MCP.

## Текущий статус

Работают календарный план, собственные задания, PDF/TXT/MD, поиск с источниками, GitHub REST и настоящий MCP stdio. Добавлен Gemini Developer API: модель выбирает инструменты в цикле function calling и формирует ответ по их результатам. Для настоящих ответов нужен ключ Google AI Studio; без ключа интерфейс честно показывает локальный алгоритм.

**Платные вызовы не разрешены.** Подключение принимает ключ только после определения его настоящего проекта через API Keys API и проверки `billingEnabled=false` через Cloud Billing API. Проверка повторяется перед каждым модельным шагом. При недоступности проверки, включённом биллинге или исчерпании квоты запрос блокируется; переключения на платную модель или Vertex нет. Не подключайте биллинг к проекту ключа: проверяется состояние на момент запроса, а не будущее состояние Google Cloud.

Gemini Developer API не заменяет обязательное размещение в GCP Agent Engine. Этот пункт хакатона ещё не выполнен. Скрипт размещения остаётся заблокированным без отдельного проекта организаторов и явного разрешения.

## Подключить бесплатный Gemini

1. Откройте [Google AI Studio → API keys](https://aistudio.google.com/api-keys). Если проекта нет в списке, нажмите Import projects и выберите свой существующий проект без биллинга.
2. Нажмите Create API key, выберите импортированный проект и создайте ключ. Не подключайте Billing, Upgrade, карту или предоплату. У проекта должен быть Free Tier. Доступ зависит от региона и квоты Google.
3. В приложении нажмите **«Подключить Gemini»**, вставьте ключ в поле пароля и нажмите **«Проверить и подключить»**. Сам ключ не отправляйте в чат и не добавляйте в исходники.
4. Для независимой проверки биллинга нужен Google ADC: `gcloud auth application-default login`, доступ к проекту ключа с `apikeys.keys.lookup` и `resourcemanager.projects.get`, а также API Keys API (`apikeys.googleapis.com`). На подготовленном компьютере ADC уже настроен. Приложение не выдаёт IAM-права и не включает API автоматически.
5. Запросите «Составь план на неделю». Настоящий ответ будет подписан `Gemini · gemini-3.1-flash-lite`, а ниже появятся фактические MCP-вызовы. Затем загрузите конспект и попросите объяснить тему со ссылкой на файл.

Разрешённая модель — `gemini-3.1-flash-lite`, имеющая Free Tier на дату проверки 17.10.2026. Нет произвольного выбора модели или платного fallback. Ошибка 429 означает ограничение бесплатной квоты, а не необходимость оплаты.

Ключ хранится в памяти локального сервера отдельно для HttpOnly-сессии браузера (до 12 часов). При перезапуске или нажатии «Отключить и удалить ключ» он удаляется. В localStorage, `.env`, экспорте и журнале ключ не сохраняется. При включённом Gemini запрос и результаты инструментов отправляются Google; в Free Tier данные могут использоваться для улучшения продуктов. Не загружайте конфиденциальные материалы.

Ключ CampusPulse Free Tier создан и подключён в локальном интерфейсе. Проект ключа определён Google API, отключённый биллинг подтверждён. Живые запросы Gemini попытались выполнить, но текущая сеть разрывает соединение с generativelanguage.googleapis.com: WinError 10054. Независимые проверки через requests и httpx без ключа подтвердили тот же сетевой отказ. Настоящий ответ модели и полный цикл Gemini → MCP → ответ пока не подтверждены. Автотесты используют подменённую модель и настоящий локальный MCP. Кнопка «Рассчитать план» всегда использует локальный MCP-планировщик и работает независимо от доступности Gemini. Чат использует Gemini при подключённом ключе; для локального поиска через чат ключ можно отключить в настройках.

## Запуск на этом компьютере

Дважды нажмите **start.cmd**. Откройте **http://127.0.0.1:8765**. Терминал должен оставаться открытым. Остановка — `Ctrl+C`.

Если порт занят уже запущенным экземпляром, откройте существующее приложение либо остановите его. Для другого порта:

```powershell
.\.venv\Scripts\python.exe -m campuspulse.server --port 8766
```

## Чистая установка

Нужен Python 3.11–3.13. Рекомендуется 3.12. Стандартных библиотек достаточно для прямых инструментов; для настоящего MCP и PDF нужны зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.cmd
```

На macOS/Linux: `python3 -m venv .venv`, `.venv/bin/pip install -r requirements.txt`, затем `CAMPUSPULSE_ALLOW_CLOUD=0 CAMPUSPULSE_MODE=local .venv/bin/python -m campuspulse.server`.

Установленные при подготовке версии Windows/Python 3.12 зафиксированы в `requirements.lock.txt`. Для воспроизводимой установки в такой же среде используйте этот файл вместо `requirements.txt`. На другой ОС используйте `requirements.txt` (lock включает Windows-зависимость pywin32). Виртуальное окружение не включается в архив и не переносится между компьютерами.

## Что попробовать

1. Нажмите «Попробовать с учебными примерами». У каждого задания есть пометка ДЕМО. Даты формируются относительно текущего дня; это не реальные задания университета.
2. Посмотрите календарь и предупреждение о просроченном задании. Раскройте результаты `list_assignments` и `plan_week` в журнале.
3. Введите собственное задание. Измените дневную нагрузку или занятые интервалы в настройках. Пересчитайте план.
4. В настройках укажите публичный репозиторий `owner/repository`. Нажмите «Задачи из GitHub». Программа получает текущие issues через GitHub REST API, а не из датасета. `due_on` берётся только из milestone. Если даты нет, задача остаётся без дедлайна. 60 минут для GitHub issue — явно указанное предположение.
5. В «Материалах» загрузите собственный PDF/TXT/MD и введите «Найди в материалах: рекурсия». Вы получите найденный фрагмент и имя файла. Для пробы есть `examples/lecture-demo.txt`.
6. Скачайте план `.ics` и при желании вручную импортируйте его в календарь. Приложение не записывает события в Google Calendar автоматически.

## Архитектура

```text
Браузер (задания, настройки; материалы в памяти вкладки)
    → локальный HTTP API (127.0.0.1)
    → локальный алгоритм ИЛИ Gemini Developer API → проверка биллинга → function calling
    → MCP client: initialize → tools/list → tools/call
    → отдельный MCP stdio server на каждый запрос
    → задания / GitHub REST / поиск по материалам / расчёт плана
    → результат + источники + журнал действий
```

Структура и компромиссы описаны в [ARCHITECTURE.md](ARCHITECTURE.md). Данные каждого запроса изолированы отдельным процессом MCP. Модель не может вызывать произвольные команды или менять выбранный пользователем репозиторий.

## MCP-инструменты

| Инструмент | Вход | Результат |
|---|---|---|
| `list_assignments` | нет | Введённые студентом задания |
| `github_assignments` | нет; репозиторий выбран пользователем | Текущие публичные issues, реальные ссылки, даты milestone |
| `plan_week` | нет | Блоки работы, риски, задачи без даты |
| `search_notes` | `query` | До пяти фрагментов с именами файлов |
| `load_context` | `context` | Служебная инициализация отдельного MCP-процесса; не передаётся Gemini как доступный инструмент |

Пример подключения внешнего MCP-клиента: `mcp-config.example.json`. Замените абсолютные пути. Для полезной работы внешний клиент сначала вызывает `load_context` с объектом из формата `POST /api/query`, поле `context`.

## HTTP API

- `GET /api/status` — режим текущей сессии, модель, транспорт, состояние подключения без ключа.
- `POST /api/gemini/connect` — `{ "api_key": "..." }`; проверяет проект и отключённый биллинг, сохраняет ключ только в памяти сессии.
- `POST /api/gemini/disconnect` — `{}`; удаляет ключ из памяти сессии.
- `POST /api/query` — `{ "message": "Составь план", "context": { "tasks": [], "hours_per_day": 3, "busy": [], "repository": "", "notes": [] } }`.
- `POST /api/extract` — `{ "name": "lecture.pdf", "data": "<base64>" }`; ответ содержит извлечённый текст. Файл не сохраняется на сервере.

Формат задания: `id`, `title`, `course`, `due` (ISO 8601 с часовым поясом или `null`), `minutes`, `done`. Занятый интервал: `start`, `end` с часовым поясом. Ответ: `answer`, `plan`, `trace`, `github`, `materials`, `mode`, `transport`.

## Ограничения и приватность

Локальная версия рассчитана на одного человека на своём компьютере. Она слушает только loopback, проверяет Host/Origin и не является публичным веб-сервисом. Нет регистрации, OAuth для календаря, фоновых напоминаний, OCR и семантического RAG. Окно для учёбы — 09:00–21:00, горизонт — семь календарных дней включая сегодня, блоки до 50 минут и перерывы по 10 минут. Алгоритм earliest deadline first не доказывает оптимальность расписания.

Задания и настройки хранятся в browser localStorage. Материалы исчезают при перезагрузке вкладки. Сервер не сохраняет тексты, файлы и историю чата; технический журнал MCP показывает имена операций. Экспорт JSON может содержать личные задания, не публикуйте его как часть исходников. Подробности: [ARCHITECTURE.md](ARCHITECTURE.md).
